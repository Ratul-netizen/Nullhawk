# Nullhawk

**The evidence-first offensive security workbench.**

Nullhawk is a web and API security testing platform for **authorized** penetration testing,
application security testing and security research: an intercepting proxy, repeater, intruder,
passive and evidence-driven active scanning, whole-app access-control testing, a scope-checked
crawler, recon tooling and reporting — in a native desktop app and a headless CLI.

> ⚠️ **For authorized security testing only.** Using Nullhawk against systems you do not own
> or have written permission to test is illegal in most jurisdictions.

🌐 **[nullhawk.com](https://nullhawk.com)**  ·  📖 **[Documentation](https://ratul-netizen.github.io/Nullhawk/)**  ·  💾 **[Download](https://github.com/Ratul-netizen/Nullhawk/releases/latest)**

## Download

Grab the installer for your OS from the [latest release](https://github.com/Ratul-netizen/Nullhawk/releases/latest):

| OS | Desktop app | CLI |
|----|-------------|-----|
| Windows | `.exe` setup or `.msi` | `nullhawk-…-windows-x86_64.exe` |
| macOS (Intel + Apple Silicon) | `.dmg` | `nullhawk-…-macos-universal` |
| Linux | `.deb`, `.rpm` or `.AppImage` | `nullhawk-…-linux-x86_64` |

Every release ships a `SHA256SUMS` file and a CycloneDX SBOM. Builds are currently unsigned —
verify the checksum before installing.
